# Manal Store — HTML / CSS / JavaScript

واجهة متجر عربي ولوحة إدارة، بدون Laravel أو خادم تطبيق أو قاعدة بيانات خارجية. جميع ملفات الموقع في `dist/`، قابلة للنشر على استضافة ثابتة. لا تحتاج npm أو build لتشغيل الموقع.

## آخر تحديث — v13

- اسم مستخدم وكلمة مرور لكل زبونة؛ يظل الدخول بالإيميل مدعومًا للحسابات السابقة.
- صفحة مستقلة لدخول الإدارة `dist/admin-login.html`، مع إعداد حساب الإدارة المحلي عند أول استخدام، بدون كلمة مرور افتراضية.
- جلسات الزبون والإدارة منفصلة في `sessionStorage`؛ تبقى الحسابات والطلبات في `localStorage`.
- منع فتح واجهة الإدارة وتنفيذ عملياتها المعتادة قبل تسجيل الدخول المحلي.
- اشتراط دخول الزبونة قبل إتمام الطلب، مع استكمال خطوة الطلب بعد التسجيل أو الدخول.
- جرس ومركز إشعارات للزبونة: تسجيل الطلب، تحديث حالته أو الدفع أو التوصيل، وأول نشر لموديل جديد. تظهر إشعارات الموديلات للحسابات النشطة الموجودة وقت النشر؛ لا تتكرر عند تعديل السعر أو إعادة الإظهار.
- حالة قراءة منفصلة لكل إشعار وحساب؛ الضغط على الإشعار يفتح الطلب أو المنتج المرتبط.
- إزالة التذييل وقسم التعليمات الطويل؛ تظهر تعليمات الطلب في نافذة تأكيد الطلب، ويمكن فتح معلومات الطلب من أعلى الصفحة.
- استمرار أيقونات طرق الدفع عبر روابط HTTPS، وخط Cairo المحلي، وتحسينات الأزرار والنوافذ الموجودة.
- تصحيح تعارض أزرار زيادة الكمية وحذف القطعة في السلة مع أزرار اختيار المقاس.
- تحديث ذاكرة PWA إلى v13، مع صفحة دخول الإدارة ضمن ملفات العمل دون اتصال.

## التشغيل

استخدمي استضافة HTTPS ثابتة أو Live Server في المحرر. افتحي `dist/index.html` عبر عنوان الخادم المحلي، ولوحة الإدارة من `dist/admin-login.html`.

يمكن أيضًا تشغيل خادم ملفات ثابت محليًا إذا كان Python مثبتًا:

```sh
cd dist
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000`. هذا خادم ملفات للتجربة فقط، وليس جزءًا من بنية التطبيق. يلزم HTTPS أو localhost لكي تعمل Web Crypto وتجزئة كلمات المرور؛ لا تفتحي ملفات الموقع مباشرة عبر `file://`.

## تجربة الحسابات والإشعارات

1. افتحي `admin-login.html` وأنشئي حساب الإدارة باسم مستخدم وكلمة مرور تختارينهما.
2. افتحي المتجر في تبويب آخر على **نفس العنوان والمتصفح**، وأنشئي حساب زبونة.
3. قدّمي طلبًا؛ سيظهر إشعار في لوحة الإدارة وفي حساب الزبونة.
4. عدّلي حالة الطلب من الإدارة؛ يظهر تحديثه في جرس الزبونة.
5. أضيفي موديلًا ظاهرًا في فئة ظاهرة؛ يظهر إشعار للمستخدمين المسجلين النشطين.
6. سجّلي خروج الزبونة وادخلي بحساب آخر؛ لا تظهر إشعارات الطلبات الخاصة بالحساب الأول.

الحسابات السابقة تظل قابلة للدخول بالإيميل، ويُنشأ لها اسم مستخدم يظهر في صفحة الحساب. جلسات الدخول القديمة لا تنتقل تلقائيًا؛ يلزم تسجيل الدخول من جديد.

## الوظائف الموجودة

- إدارة المنتجات والفئات والإعلانات وصور المنتجات ومخزون المقاسات.
- البحث والتصفية والسلة وطلب بمقاس وكمية والتحقق من تغيّر السعر والمخزون.
- رسوم توصيل حسب المحافظة مع دعم التوصيل المجاني وحفظ سعر الطلب السابق.
- الدفع عند الاستلام أو حوالة يدوية مع صورة الإشعار؛ لا يوجد تكامل بوابة دفع.
- حالات الطلب والدفع والتوصيل، والمندوب والتتبع، وإعادة المخزون عند الإلغاء مرة واحدة.
- إشعارات الإدارة للطلبات والزيارات المحلية، وإشعارات الحسابات للموديلات والطلبات.
- PWA وخط Cairo وأصول محلية وهوية الأسود والأبيض والذهبي.

## حدود هذه النسخة

**هذه واجهة محلية، وليست متجرًا متصلًا بين الأجهزة.** بيانات متصفح أو جهاز لا تصل إلى جهاز آخر، ولا تُرسل طلبات فعلية أو رسائل بريد أو Push عند إغلاق الموقع. إشعارات الجرس داخل الموقع فقط، وتتزامن بين تبويبات المتصفح نفسه.

دخول الإدارة وقيود JavaScript لا توفر حماية خادم: من يملك وصولًا للمتصفح يستطيع تعديل البيانات والكود المحلي. تجزئة كلمات المرور بـ PBKDF2 ليست بديلًا عن مصادقة خادم. كل متصفح جديد يستطيع إعداد حساب إدارة محلي خاص به. لا توجد كلمة مرور أو حساب حقيقي مضمّن في المستودع. تجنبي إدخال معلومات حساسة أو بيانات طلبات حقيقية في هذه النسخة.

مسح بيانات المتصفح يحذف الحسابات والطلبات والإعدادات. المخزون ليس مناسبًا لطلبات متزامنة من أجهزة مختلفة. للتحويل إلى متجر فعلي لاحقًا، يمكن إبقاء HTML/CSS/JavaScript وربطها بخدمة خارجية للمصادقة والبيانات والصور والإشعارات.

## التحقق للمطورين

Node.js مطلوب فقط لتشغيل الاختبارات، وليس لتشغيل الموقع:

```sh
node tests/store-flows.mjs
node tests/ui-interactions.mjs
node tests/static-checks.mjs
```

تشمل الاختبارات منطق الطلبات والمخزون والحسابات والإشعارات والتوافق مع البيانات السابقة، وفحوصات تفاعل النوافذ والملفات الثابتة. فحص النوافذ محاكاة DOM وليس مراجعة بصرية في متصفح.
